# Quarterly report helper

Small scripts that pull the regional sales CSVs from the shared drive, clean them with pandas and
produce the charts for the quarterly business review deck.

## Usage

    python report.py --quarter Q3 --region EMEA

Ask the team channel if the shared drive path changed.
